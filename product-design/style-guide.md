# BidServe Brand Identity & Style Guide

## Logo
![BidServe Logo](./logo.png)

## Color Palette
| Color | Hex | Usage |
|-------|-----|-------|
| Primary Navy | `#003366` | Headers, Primary Buttons, Branding |
| Secondary Teal | `#00BFA5` | Call to Action, Icons, Accents |
| Background Gray | `#F5F7FA` | App Backgrounds |
| Surface White | `#FFFFFF` | Cards, Input Fields |
| Text Dark | `#1A1A1A` | Main Body Text |
| Text Muted | `#757575` | Secondary Labels |

## Typography
- **Headings:** Montserrat (Bold)
- **Body:** Inter (Regular, Medium)
- **Buttons/Labels:** Inter (Semi-bold)

## Component Styles
- **Buttons:** Rounded (8px), Primary Navy background, White text.
- **Cards:** White background, Soft shadow (0 4px 6px rgba(0,0,0,0.05)), 12px border radius.
- **Inputs:** Light gray border (1px), rounded 8px.
